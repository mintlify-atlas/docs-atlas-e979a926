WidevineProxy2 is a Manifest V3 browser extension for Chrome and Firefox that proxies Widevine and ClearKey Encrypted Media Extensions (EME) license challenges. It re-signs license requests with your own CDM device before they reach the web player, bypassing one-time tokens, request hashes, and license wrapping — then surfaces the extracted decryption keys directly in the popup UI.

## How It Works

<Steps>
  <Step title="Install the extension">
    Download the latest release ZIP (Chrome) or XPI (Firefox) from the [GitHub releases page](https://github.com/DevLARLEY/WidevineProxy2/releases/latest) and load it in your browser.
  </Step>
  <Step title="Load a Widevine device">
    In the popup, select either **Widevine Device** (.wvd file) or **Remote CDM** (remote.json) and use the file picker to import your device credentials.
  </Step>
  <Step title="Play a DRM-protected video">
    Navigate to any page that uses Widevine or ClearKey DRM and start playback. WidevineProxy2 intercepts the EME challenge automatically.
  </Step>
  <Step title="Copy keys and build your download command">
    The popup **Keys** section shows extracted `kid:key` pairs. If a manifest URL was detected, a ready-to-run download command is generated automatically.
  </Step>
</Steps>

## Key Features

<CardGroup cols={2}>
  <Card title="Challenge Interception" icon="filter">
    Hooks `MediaKeySession.addEventListener` and `update` in the page's main world to intercept and re-sign Widevine challenges before they reach the license server.
  </Card>
  <Card title="Bypass Protections" icon="shield-halved">
    Defeats one-time tokens, request hashes, and license message wrapping by resigning the raw protobuf challenge with your device's RSA private key.
  </Card>
  <Card title="Dual Device Support" icon="arrows-split-up-and-left">
    Use a local `.wvd` file for fully offline signing, or delegate to a remote pywidevine-compatible CDM API server.
  </Card>
  <Card title="Manifest Detection" icon="magnifying-glass">
    Automatically detects DASH (MPD), HLS (m3u8), and Smooth Streaming manifests via XHR and Fetch proxies, then pairs them with captured keys.
  </Card>
</CardGroup>
